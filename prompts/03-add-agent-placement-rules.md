# Prompt 03: Add Agent Placement Rules

Copy this into your agent after `DIRECTORY_ATLAS.md` exists.

```text
Please add clear placement rules to my main AGENTS.md file.

Goal:
Future agents should know when to consult DIRECTORY_ATLAS.md, how to choose where files go, and when to stop guessing.

Rules:
- Do not replace my whole AGENTS.md unless I explicitly ask.
- Preserve existing instructions.
- Add a focused section for directory placement and organization.
- Make the rules practical, not theoretical.
- If AGENTS.md does not exist, propose creating one and show me the contents first.

The section should say:
1. Consult DIRECTORY_ATLAS.md before saving, creating, moving, or organizing durable files.
2. Read local AGENTS.md files in relevant subfolders when they exist.
3. Search existing homes before creating a new folder.
4. Prefer established structure.
5. Ask before creating a new top-level durable folder.
6. Treat memory, credentials, backups, browser profiles, runtime folders, caches, and private data as protected.
7. Record important decisions or follow-ups in the right file, not only chat.

After editing, report:
- the file changed
- the section added
- any existing rules you preserved
- anything you were unsure about
```
