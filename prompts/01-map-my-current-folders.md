# Prompt 01: Map My Current Folders

Copy this into your agent.

```text
Please inspect my current agent workspace and make a safe folder map.

Rules:
- Do not delete, move, rename, publish, or upload anything.
- Do not deeply read private or sensitive contents.
- Prefer folder names, existing README files, existing AGENTS.md files, and obvious structure.
- If you find credentials, backups, browser profiles, private messages, memory files, caches, or runtime folders, mark them as protected instead of summarizing their contents.
- Search for existing homes before suggesting any new folder.

Please return:
1. The workspace root you inspected.
2. The major folders you found and what each one appears to mean.
3. Which folders look like active projects.
4. Which folders look like research, reports, references, templates, logs, memory, generated output, or archives.
5. Which folders should be protected from deep indexing or public summaries.
6. Any unclear folders I need to explain.
7. Your proposed next step before creating or editing any files.
```
