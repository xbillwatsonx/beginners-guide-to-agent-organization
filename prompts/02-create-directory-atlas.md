# Prompt 02: Create Directory Atlas

Copy this into your agent after it has mapped your folders.

```text
Please create or update a file named DIRECTORY_ATLAS.md in my agent workspace.

Goal:
Make a short, curated placement map that future agents can read before creating durable files or folders.

Rules:
- The atlas is not a full directory tree.
- Do not expose private file contents.
- Mention protected areas only by purpose and boundary.
- Prefer existing folder homes.
- If a destination is unclear, write that the agent should ask me before creating a new durable folder.
- Keep the wording beginner-friendly.

The atlas should include:
1. Purpose of the atlas.
2. Placement order for future agents.
3. Major folder homes and what belongs in each.
4. What does not belong in each major home when useful.
5. Protected areas and boundaries.
6. A rule for creating new durable folders.
7. A note that local AGENTS.md files should be read when working inside governed folders.

Before editing, show me the proposed outline and the file path you plan to write.
After editing, report what changed and where.
```
