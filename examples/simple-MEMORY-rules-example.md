# Simple Memory Rules Example

This example shows the level of detail a small workspace can use.

## Long-Term Memory

Use long-term memory for durable preferences, standing rules, important active projects, and recurring lessons.

## Daily Notes

Use daily notes for session summaries, temporary context, progress notes, and short-term follow-ups.

## Project Files

Use project files for implementation details, decisions, research, reports, and review notes.

## Do Not Remember

Do not store secrets, one-time command output, private content copied without a reason, or details that already live in a clear file path.
