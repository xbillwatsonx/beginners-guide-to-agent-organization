# Memory Rules

Long-term memory is for durable information that should shape future work.

## Put In Long-Term Memory

- durable user preferences
- durable operating rules
- important active projects
- recurring lessons
- important decisions that future agents need

## Put In Daily Notes

- session summaries
- temporary details
- progress notes
- raw context that may matter soon
- follow-ups that are not permanent rules

## Put In Project Files

- project plans
- implementation details
- research findings
- final reports
- review notes
- files other people may need to read

## Do Not Remember

- secrets
- one-time tool noise
- private contents copied without a reason
- details that belong in a file path already
- outdated status after the work is complete

## Agent Rule

If something may matter later, write it down in the right place. Do not rely on chat alone.
