# Directory Atlas

Use this file before deciding where durable files or folders belong.

## Placement Order

1. Check this atlas.
2. Read local instructions in the folder you plan to edit.
3. Search existing homes.
4. Prefer established structure.
5. Ask before creating a new durable top-level folder.

## Starter Homes

| Path | Use when |
|------|----------|
| `PROJECTS/` | Active project work. |
| `RESEARCH/` | Research in progress. |
| `REPORTS/` | Finished reviews, audits, and summaries. |
| `REFERENCE/` | Durable knowledge and reference material. |
| `TEMPLATES/` | Reusable starter files. |
| `memory/` | Daily notes and continuity. |

## Protected Areas

Do not deeply summarize or expose credentials, backups, browser profiles, private messages, runtime caches, generated vendor folders, or memory files unless the user gives a specific reason.

## New Folder Rule

Search first. Explain the proposed location. Ask if the folder is durable, top-level, sensitive, or unclear.
